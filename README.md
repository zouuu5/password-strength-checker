# 🔐 Password Strength Checker

A simple and effective Python script that evaluates the strength of a password based on multiple criteria including length, letter case, digits, and special characters.

---

## ✅ Features

- Evaluates password strength based on:
  - Minimum length
  - Uppercase and lowercase characters
  - Numeric digits
  - Special characters
- Provides clear feedback:
  - **Weak**
  - **Moderate**
  - **Strong**

---

## 💻 Usage

1. Clone this repository or download the script.
2. Run the script using Python:

```bash
python password_strength_checker.py
